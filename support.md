说明你执行的操作、预期结果与实际结果，并提供不含敏感信息的截图。若需要样例，优先构造小型合成文件。没有源文件也可以先报告，我们会根据描述继续沟通。

## Quick start
- Select a calibration task and create it.
- Import the required frames or load the built-in synthetic demo.
- Review matching checks, confirm the inputs, and run.
- Inspect the results and export to a selected folder.

## Data and scope
Uses strict exposure matching and does not scale dark frames by exposure. Invalid pixels and low-response flat pixels are masked by the algorithm. Processing size depends on iPad memory and app resource limits. Sessions and results are held during the current run; export before ending it. Recent workflow history does not restore input files or results.

## Saving and backups
Selected FITS files are read and processed locally. Working sessions and generated results are primarily held in memory and temporary workspace. The app may retain recent workflow categories and interface settings; complete results must be exported by the user.
Export important work and retain source files before offloading or deleting the app. Offload App and Delete App can have different effects; check the actual system option on your iPad.

## Frequently asked questions

### Why is an exposure mismatch reported?
The algorithm requires matching exposures and does not automatically scale dark frames. Use matched inputs.

### Why are previous results missing after reopening?
Complete sessions do not persist across launches. Export FITS products and the report before ending the session.

### A file is missing from the picker, or a cloud file will not open
In Files, confirm the file is fully downloaded, accessible, and in a supported format. Try a local copy under On My iPad. A matching filename extension does not guarantee a supported internal structure.

### How should I report a problem?
Describe the action, expected result, and actual result, with screenshots free of sensitive information. If an example is needed, prefer a small synthetic file. You may report the problem without a source file first; we can follow up from your description.

## Privacy
No account is required and core processing takes place on your device. Read the privacy policy in this folder for local storage, file services, and voluntary support communications.
